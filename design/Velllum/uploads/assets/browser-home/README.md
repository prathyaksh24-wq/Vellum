# Browser homepage assets

The five original wallpapers were generated for the user-approved Vellum browser
designs on 2026-10-07. They contain artwork only: controls, titles, forms and
shortcuts are live UI. The source PNGs retain their generation metadata.

| File | Approved direction |
| --- | --- |
| google.png | Pixel clouds and rolling green hills |
| brave.png | Blue pixel hardware, cables and sleeping cat |
| duckduckgo.png | Turquoise underwater cartoon landscape |
| startpage.png | Illustrated moonlit lake, forest and mountain village |
| searxng.png | Teal retro desktop with cursor cascade |

Brand files are used to identify the selected provider, not to imply affiliation:
- google-logo.png: https://www.google.com/images/branding/googlelogo/2x/googlelogo_color_272x92dp.png
- google.ico: https://www.google.com/favicon.ico
- duckduckgo-logo.png: https://duckduckgo.com/assets/icons/meta/DDG-icon_256x256.png
- brave.svg, startpage.svg, searxng.svg, github.svg, wikipedia.svg, youtube.svg:
  Simple Icons v15, https://github.com/simple-icons/simple-icons (CC0; brand trademark rights remain with their owners).

`icons/` contains standard Lucide icons rendered from the existing installed
lucide-react dependency (ISC): https://github.com/lucide-icons/lucide.
No custom illustration is drawn in CSS or SVG.
