Resolve the server, channel or thread, person and timeframe before reading. Use the installed bot and approved channels. An account archive covers the user's authored messages, not whole server conversations. Summarize what participants actually said and identify missing coverage. Keep private message bodies inside DiscordAgent. External actions use the existing confirmation-bound handler; never impersonate the user.
