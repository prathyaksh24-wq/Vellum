# Vellum Domain Glossary

- **YouTube channel entity**: one local canonical entity keyed by an official YouTube channel ID.
- **Channel alias**: a title observed for that same channel ID, preserved so renames do not create a second local entity.
- **Identity collision candidate**: a normalized alias linked to distinct channel IDs. It is a review item, not an instruction to merge.
- **Cross-channel merge**: combining two distinct external channel IDs. This is deferred and never automatic in the current scope.
