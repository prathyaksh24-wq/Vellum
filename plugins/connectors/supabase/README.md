# Supabase

Official hosted Supabase MCP with per-user OAuth, all documented feature groups
including Storage, deferred schemas and reviewed operations. See
[connection and limitations](../../../docs/supabase.md).

Choose the intended organization in the Supabase consent flow. Account access,
project permissions, plan limits and any additional server confirmations apply.
No Supabase project records are read or modified by the connection check.
