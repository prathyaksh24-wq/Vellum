# GitMCP

Public repository documentation and code through https://gitmcp.io/docs.
Upstream source: https://github.com/idosal/git-mcp (Apache-2.0).
The logo is the upstream `https://gitmcp.io/img/icon_cropped.png` asset.

No OAuth, API key, or GitHub account is needed. Private repositories, issues,
pull requests, and GitHub mutations belong to the separate GitHub connector.

Vellum retains its deferred repo_docs tool with all five actions: match,
fetch_docs, search_docs, search_code, and fetch_url. PluginMcpRuntime exposes the
complete live catalog on demand. Known public operations are classified as reads
only on the exact official generic endpoint. New tools retain server annotations
and the existing approval policy.

GITMCP_MCP_URL remains configurable. Disable or uninstall the plugin to block
both adapters. Configuration availability is separate from live verification.
