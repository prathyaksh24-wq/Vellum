# Airtable

Official Airtable MCP connection, owned by `agent.plugins.airtable`.
See [connection and coverage](../../../docs/airtable.md).

Choose Sign in with Airtable, approve the resources you want Vellum to access,
and return to the original app. Tokens stay in the OS credential store.
Every published MCP tool is discoverable on demand; changes require exact-input review.
