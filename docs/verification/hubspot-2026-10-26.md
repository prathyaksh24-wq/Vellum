The user saved app setup successfully (`app_registered: true`) but reported an
error on HubSpot's regional authorization page before any callback. The user
confirmed the initial registered callback exactly matched Vellum's numeric
loopback callback. HubSpot's official redirect rule allows HTTP only for literal
localhost; changed this provider's callback and setup instructions to
`http://localhost:8000/api/plugins/hubspot/oauth/callback`. The existing connector
needs its registered redirect edited to match. No client secret was replaced and
no new app was registered. Anonymous entry checks with and without the resource
indicator both returned the OAuth page, so they did not identify a resource error.

After changing the existing app's registered redirect to localhost and retrying,
the user reported connecting and returning to Vellum. Guarded local status

registration, client secret, access token, refresh token and expiry were saved in

written to source, manifests, `.env` or action history. The successful retry
