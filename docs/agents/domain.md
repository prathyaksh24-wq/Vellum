# Domain Docs

Vellum uses a single-context domain layout.

Before planning or implementation:

1. Read `CONTEXT.md`.
2. Read relevant decisions under `docs/adr/` when present.
3. Use the glossary's canonical vocabulary in specifications, tickets, tests, APIs, and implementation.
4. Surface conflicts with existing decisions instead of silently overriding them.
5. Add vocabulary or ADRs only when a discussion resolves a genuine domain ambiguity or durable architectural decision.
